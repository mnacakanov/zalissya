# Ready-made models (CC0)

- `kenney/tree-big.gltf`, `kenney/tree-small.gltf`: trees by Kenney
  (kenney.nl), CC0 1.0 (public domain), as published in the pmndrs market
  assets (github.com/pmndrs/market-assets, `files/models/tree-big`,
  `tree-small`). Used as a sample of the "ready-made pack" approach to the
  forest, rendered from the game's camera like our own models
  (`kenney_*.js`).
